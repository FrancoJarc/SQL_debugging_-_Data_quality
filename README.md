# SQL_debugging_&_Data_quality

## Descripción

Proyecto enfocado en el análisis, validación y corrección de consultas SQL.

El objetivo es detectar errores lógicos que pueden generar resultados incorrectos en reportes analíticos y comprender cómo afectan a las métricas de negocio.

---

## Objetivos

- Analizar consultas SQL existentes.
- Identificar errores de lógica.
- Corregir consultas defectuosas.
- Validar resultados obtenidos.
- Explicar el impacto de cada corrección.

---

## Caso analizado

Una consulta que calcula gasto promedio por ciudad presenta resultados inconsistentes.

Durante el análisis se estudian:

- JOINs.
- Filtros.
- Agregaciones.
- Tratamiento de valores nulos.
- Impacto de WHERE sobre LEFT JOIN.
